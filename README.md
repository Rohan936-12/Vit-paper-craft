# Vit-paper-craft
Beginner friendly exploration of vision Transformers and vit research paper


###Vision Transformer (ViT) — Paper Craft

About the Paper

This project is based on the research paper “An Image Is Worth 16×16 Words: Transformers for Image Recognition at Scale” by Alexey Dosovitskiy and other authors.

Paper: https://arxiv.org/abs/2010.11929

Main Idea

The paper introduces Vision Transformer (ViT), a method that uses a Transformer for image recognition. Instead of processing an image as a whole, it divides the image into small patches and treats them like tokens in a sequence.

What I Learned

- Transformers can be used for image recognition, not just language tasks.
- Images can be divided into patches and processed by a Transformer.
- Training on large datasets is important for achieving good results.
- CNNs can have advantages when the amount of training data is limited.

Project Goals

- Understand the main idea behind Vision Transformers.
- Demonstrate how an image can be divided into patches.
- Explore the paper's approach and possible experiments.

Project Status

This is a learning project based on reading the original research paper. Any demonstrations and experiments will be documented as they are implemented.

Reference

Dosovitskiy, A. et al. An Image Is Worth 16×16 Words: Transformers for Image Recognition at Scale. ICLR 2021.
